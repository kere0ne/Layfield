The better UI library for Roblox scripts

Example is a compact, smooth interface suite for executor scripts. Rayfield-style layout, rebuilt smaller and faster: tabs with live search, animated toggles, rebindable keybinds and toast notifications, all open source.

Introduction

Example is a UI library you drop into any Roblox executor script. You write features (toggles, sliders, buttons), it draws the window: dragging, keybinds, search, notifications, all handled. The library lives in this repo's src/ modules and loads over the network, so pushing an update to the repo updates everyone using your loader.

  • Compact Rayfield-style window: 520x340 by default, title bar, left tab sidebar, dense rows
  • Live search in the sidebar filters the current tab's elements as you type
  • Toggle rows with animated switch and rebindable keybind chip
  • Buttons, sliders, dropdowns, text inputs, paragraphs, standalone keybinds
  • Toast notifications top right with a countdown bar
  • Touch friendly: drag and tap work on mobile executors, window stays clamped to screen

Quick start

Three steps.

  1. Open your executor.
  2. Paste this one-liner to run the demo hub:
lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/kere0ne/Example/main/main.lua"))()
  1. Build your own hub: open main.lua in the repo, edit the CONFIG table and the FEATURES block at the bottom, and paste the whole file. The templates in there cover every element.
If the window does not appear, your executor may block game:HttpGet to raw.githubusercontent.com. Try another executor or self-host the modules (see Make it yours).

Window

lua
local Example = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/kere0ne/Example/main/src/init.lua"
))()

local Window = Example:CreateWindow({
    Name = "Example Hub",            -- title bar text
    Subtitle = "demo",               -- shown in toasts
    Version = "v2.3",                -- version pill
    Icon = "E",                      -- letter in the accent badge
    AccentColor = Color3.fromRGB(68, 140, 255),
    ToggleKey = Enum.KeyCode.LeftControl,  -- key that minimizes the GUI
    Width = 520,                     -- window width, 380 to 760
    Height = 340,                    -- window height, 260 to 600
    DefaultTab = "Main",             -- auto-created tab name
})

Tabs & search

Tabs split your features into pages down the left sidebar. A tab is an object: add elements to it with the same calls you use on the window.

lua
local Movement = Window:Tab("Movement", ">")   -- name, optional icon
local Player   = Window:Tab("Player", "@")
local Utility  = Window:Tab("Utility")

Movement:Toggle({ Name = "Inf Jump", ... })
Player:Slider({ Name = "Walk Speed", ... })

Window:SelectTab(Utility)   -- switch pages from code

If you skip tabs entirely, a Main tab is created for you and window:Toggle(...) and friends go straight to it, so simple hubs need no tab code at all. The search box at the top of the sidebar filters the current tab's elements live while you type.

Toggle

A compact feature row: name, animated switch, rebindable keybind chip.

lua
local infJump = Window:Toggle({
    Name = "Inf Jump",              -- row title (also what search matches)
    Default = false,                -- starting state
    Keybind = Enum.KeyCode.I,       -- optional starting keybind
    Callback = function(state)      -- fires on every change, including keybind presses
        -- your logic here
    end,
})

infJump:Set(true)          -- turn it on from code (fires the callback)
print(infJump:Get())       -- current state
infJump:SetKeybind(Enum.KeyCode.J)  -- change the keybind from code

Users can click the KEY chip at any time and press a key to rebind it. Keybinds are ignored while typing in a text box, so they never fight with chat or search.

Button

lua
Window:Button({
    Name = "Rejoin Server",
    Callback = function()
        game:GetService("TeleportService"):Teleport(game.PlaceId, game.Players.LocalPlayer)
    end,
})

Slider

lua
Window:Slider({
    Name = "Walk Speed",
    Min = 16, Max = 100,
    Default = 16,
    Suffix = "",                -- shown after the value, e.g. "s" or "%"
    Whole = true,               -- false allows one decimal place
    Callback = function(value)
        local hum = game.Players.LocalPlayer.Character
            and game.Players.LocalPlayer.Character:FindFirstChildOfClass("Humanoid")
        if hum then hum.WalkSpeed = value end
    end,
})

-- returned object: slider:Set(50), slider:Get()

Dropdown

lua
local themePick = Window:Dropdown({
    Name = "Accent",
    Options = {"Blue", "Purple", "Green", "Orange", "Red"},
    Default = "Blue",
    Callback = function(choice)
        print("picked", choice)
    end,
})

-- returned object: themePick:Set("Green"), themePick:Get()

The list opens under the row and closes when you pick an option or click anywhere else.

Input

lua
Window:Input({
    Name = "Custom Speed",
    Placeholder = "16-100",
    Default = "",
    Callback = function(text, enterPressed)
        -- fires when the box loses focus; enterPressed is true on Enter
    end,
})

-- returned object: input:Set("new text"), input:Get()

Paragraph

A text block that grows to fit its content. Good for notes, credits or instructions inside your hub.

lua
Window:Paragraph({
    Title = "Welcome",
    Text = "Press LeftControl to hide the GUI. Click a KEY chip to rebind a feature.",
})

Keybind

A standalone keybind for actions that are not toggles (a panic key, a teleport, anything).

lua
Window:Keybind({
    Name = "Panic Key",
    Default = Enum.KeyCode.P,
    Callback = function()
        -- unload everything, teleport, whatever you need
    end,
})

-- returned object: kb:SetKeybind(Enum.KeyCode.X), kb:Get()

Section & Label

lua
Window:Section("Movement")     -- small uppercase divider heading
Window:Label("drag the title bar to move the window")  -- dim helper text

Mobile panel

A quick-action button grid floating over gameplay, like mobile game hubs: big rounded buttons, draggable, on the left or right side.

lua
local Panel = Window:MobilePanel({ Side = "Right" })   -- or "Left"

Panel:Button({ Name = "TP Down",   Callback = function() end })
Panel:Button({ Name = "Reset",     Callback = function() end })
Panel:Button({ Name = "Aim Assist", Callback = function() end })

Panel:SetSide("Left")      -- move the whole grid from code
Panel:SetVisible(false)    -- hide / show it
Panel:Destroy()

Buttons auto-wrap onto a two-column grid (set Columns in the config for up to four), flash the accent color when pressed, and the panel drags by its empty space so button taps stay clean.

Notifications

lua
Window:Notify({
    Title = "Example Hub",
    Text = "system online",
    Icon = "E",
    Duration = 4,     -- seconds before it fades out
})

Toasts stack in the top right of the screen with a countdown bar and slide away on their own.

Config saving

Rayfield-style flag saving. Give any toggle, slider, dropdown or input a Flag name and its value is saved to a local config file (via writefile, when your executor supports it) and restored automatically the next time the hub loads.

lua
Window:Toggle({
    Name = "Inf Jump",
    Flag = "InfJump",          -- value saved/restored under this name
    Default = false,
    Callback = function(state) end,
})

Window:SaveConfig("myconfig")   -- save now under a custom name
Window:LoadConfig("myconfig")   -- load a saved config from code

Saving is debounced (half a second after the last change) and restore happens about a second after startup, once your features exist. Turning SaveConfigs off in the window config disables it entirely.

Theming

Every color lives in src/theme.lua. Edit that one table and the whole library re-skins; it reloads from your repo on the next run. AccentColor in the window config overrides the accent per window without touching the theme file.

lua
return {
    Window    = Color3.fromRGB(14, 16, 24),   -- window background
    Sidebar   = Color3.fromRGB(18, 21, 31),   -- tab sidebar
    Header    = Color3.fromRGB(22, 25, 37),   -- title bar / toasts
    Card      = Color3.fromRGB(26, 30, 43),   -- element rows
    CardHover = Color3.fromRGB(34, 39, 56),   -- hover state
    Chip      = Color3.fromRGB(42, 48, 68),   -- keybind chips, tracks
    Stroke    = Color3.fromRGB(50, 56, 80),   -- borders
    Text      = Color3.fromRGB(235, 239, 250),
    SubText   = Color3.fromRGB(140, 147, 172),
    Off       = Color3.fromRGB(52, 58, 84),   -- switch when off
    Accent    = Color3.fromRGB(68, 140, 255), -- default accent
}

Feature templates

Every element in one place, ready to paste into the FEATURES block in main.lua:

lua
local Window = Example:CreateWindow({
    Name = "Example Hub", Version = "v2.3", Icon = "E",
    AccentColor = Color3.fromRGB(68, 140, 255),
})

local Movement = Window:Tab("Movement")

Movement:Toggle({ Name = "Anti Bat", Keybind = Enum.KeyCode.O,
    Callback = function(state) --[[ your logic ]] end })

Movement:Toggle({ Name = "Anti Ragdoll", Default = true, Keybind = Enum.KeyCode.R,
    Callback = function(state)
        local char = game.Players.LocalPlayer.Character
        local hum = char and char:FindFirstChildOfClass("Humanoid")
        if hum then
            hum:SetStateEnabled(Enum.HumanoidStateType.Ragdoll, not state)
            hum:SetStateEnabled(Enum.HumanoidStateType.FallingDown, not state)
        end
    end })

Window:Button({ Name = "Unload GUI", Callback = function() Example:Destroy() end })

Window:Notify({ Title = "Example Hub", Text = "system online", Icon = "E" })

Make it yours

  • Fork this repo (or copy it) so the modules load from your account, then change the kere0ne/Example URL inside src/init.lua and in your loader to your own repo.
  • Rename it: set Name, Icon and Version in main.lua's CONFIG table. That is your hub's branding.
  • Add features: put your logic in the callbacks. Every element call returns an object with Set/Get so your scripts can read and drive the UI.
  • Update safely: because modules load from the repo, editing them on GitHub updates every user on their next execute. Test locally with a copy before pushing big changes.
