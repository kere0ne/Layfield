Layfield

A modern script hub UI framework for Roblox. Rayfield-style layout, rebuilt better: tabs, live search, animated toggles, rebindable keybinds and toast notifications, all in a few small modules.

version v2.0 lua / luau mobile friendly

Intro

Layfield is a UI library you drop into any Roblox executor script. You write features (toggles, sliders, buttons), it draws the window, handles dragging, keybinds, search and notifications. The library lives in this repo's src/ modules and loads over the network, so pushing an update to the repo updates everyone using your loader.

  • Tabs with a tab bar, plus a live search box that filters elements as you type
  • Toggle cards with icon, ACTIVE/INACTIVE pill, animated switch and click-to-rebind keybind
  • Buttons, sliders, dropdowns, text inputs, paragraphs, standalone keybinds
  • Toast notifications with a countdown bar
  • Draggable window (clamped to screen), minimize button and a global toggle key (LeftControl by default)
  • Touch friendly: drag and tap work on mobile executors

Quick start

Three steps.

  • 1. Open your executor.
  • 2. Paste this one-liner to run the demo hub:
lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/kere0ne/Layfield/main/main.lua"))()
  • 3. To build your own hub, open main.lua in the repo, edit the CONFIG table and the YOUR FEATURES block at the bottom, and paste the whole file instead. Look at example.lua for a full working demo you can copy from.
If the window does not appear, your executor may block game:HttpGet to raw.githubusercontent.com. Try another executor or self-host the modules (see Make it yours).

Window config

lua
local Layfield = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/kere0ne/Layfield/main/src/init.lua"
))()

local Window = Layfield:CreateWindow({
    Name = "Example Hub",           -- header title
    Subtitle = "example hub",   -- small text under the title
    Version = "v3.0",               -- version pill
    Icon = "E",                     -- letter in the accent badge
    AccentColor = Color3.fromRGB(45, 145, 255),
    ToggleKey = Enum.KeyCode.LeftControl,  -- key that minimizes the GUI
    Width = 460,                    -- window width in pixels
    DefaultTab = "Main",            -- name of the auto-created tab
})

Tabs & search

Tabs split your features into pages. A tab is an object: add elements to it with the same calls you use on the window.

lua
local Movement = Window:Tab("Movement", ">")   -- name, optional icon
local Player   = Window:Tab("Player", "@")
local Utility  = Window:Tab("Utility")

Movement:Toggle({ Name = "Inf Jump", ... })
Player:Slider({ Name = "Walk Speed", ... })

Window:SelectTab(Utility)   -- switch pages from code

If you skip tabs entirely, a Main tab is created for you and window:Toggle(...) and friends go straight to it, so simple hubs need no tab code at all. The search box on the tab bar filters the current tab's elements live while you type.

Toggle

A feature card: icon, name, status pill, animated switch and a rebindable keybind.

lua
local infJump = Window:Toggle({
    Name = "Inf Jump",              -- card title (also what search matches)
    Icon = "^",                     -- short glyph in the icon box
    Default = false,                -- starting state
    Keybind = Enum.KeyCode.I,       -- optional starting keybind
    Callback = function(state)      -- fires on every change, including keybind presses
        -- your logic here
    end,
})

infJump:Set(true)          -- turn it on from code (fires the callback)
print(infJump:Get())       -- current state
infJump:SetKeybind(Enum.KeyCode.J)  -- change the keybind from code

Users can click the KEY chip at any time and press a key to rebind it. Keybinds are ignored while typing in a text box, so they never fight with chat or search.

Button

lua
Window:Button({
    Name = "Rejoin Server",
    Icon = ">",                 -- optional
    Callback = function()
        game:GetService("TeleportService"):Teleport(game.PlaceId, game.Players.LocalPlayer)
    end,
})

Slider

lua
Window:Slider({
    Name = "Walk Speed",
    Min = 16, Max = 100,
    Default = 16,
    Suffix = "",                -- shown after the value, e.g. "s" or "%"
    Whole = true,               -- false allows one decimal place
    Callback = function(value)
        local hum = game.Players.LocalPlayer.Character
            and game.Players.LocalPlayer.Character:FindFirstChildOfClass("Humanoid")
        if hum then hum.WalkSpeed = value end
    end,
})

-- returned object: slider:Set(50), slider:Get()

Dropdown

lua
local themePick = Window:Dropdown({
    Name = "Accent",
    Options = {"Blue", "Purple", "Green", "Orange", "Red"},
    Default = "Blue",
    Callback = function(choice)
        print("picked", choice)
    end,
})

-- returned object: themePick:Set("Green"), themePick:Get()

The list opens under the card and closes when you pick an option or click anywhere else.

Input

lua
Window:Input({
    Name = "Webhook URL",
    Placeholder = "https://discord.com/api/webhooks/...",
    Default = "",
    Callback = function(text, enterPressed)
        -- fires when the box loses focus; enterPressed is true on Enter
    end,
})

-- returned object: input:Set("new text"), input:Get()

Paragraph

A text block that grows to fit its content. Good for notes, credits or instructions inside your hub.

lua
Window:Paragraph({
    Title = "Welcome",
    Text = "Press LeftControl to hide the GUI. Click a KEY chip to rebind a feature.",
})

Keybind

A standalone keybind for actions that are not toggles (a panic key, a teleport, anything).

lua
Window:Keybind({
    Name = "Panic Key",
    Default = Enum.KeyCode.P,
    Callback = function()
        -- unload everything, teleport, whatever you need
    end,
})

-- returned object: kb:SetKeybind(Enum.KeyCode.X), kb:Get()

Section & Label

lua
Window:Section("Movement")     -- small uppercase divider heading

Notifications

lua
Window:Notify({
    Title = "Example Hub",
    Text = "system online",
    Icon = "E",
    Duration = 3,     -- seconds before it fades out
})

Toasts stack in the top center of the screen with a countdown bar and slide away on their own.

Theming

Every color lives in src/theme.lua. Edit that one table and the whole library re-skins; it reloads from your repo on the next run. AccentColor in the window config overrides the accent per window without touching the theme file.

lua
return {
    Window    = Color3.fromRGB(15, 17, 25),   -- window background
    Header    = Color3.fromRGB(26, 30, 44),   -- header / tab bar / toasts
    Card      = Color3.fromRGB(29, 33, 47),   -- element cards
    CardHover = Color3.fromRGB(38, 43, 61),   -- hover state
    Chip      = Color3.fromRGB(46, 52, 74),   -- pills, keybind chips, track
    Stroke    = Color3.fromRGB(56, 62, 88),   -- card borders
    Text      = Color3.fromRGB(238, 241, 250),
    SubText   = Color3.fromRGB(146, 153, 178),
    Off       = Color3.fromRGB(58, 64, 92),   -- switch when off
    Accent    = Color3.fromRGB(52, 142, 255), -- default accent
}

Full example

example.lua in the repo is a complete working hub with working Inf Jump and Anti Ragdoll. The core of it:

lua
local Window = Layfield:CreateWindow({
    Name = "Example Hub", Subtitle = "example hub",
    Version = "v3.0", Icon = "E",
    AccentColor = Color3.fromRGB(45, 145, 255),
})

Window:Section("Movement")

Window:Toggle({ Name = "Anti Bat", Icon = "<>", Keybind = Enum.KeyCode.O,
    Callback = function(state) --[[ your logic ]] end })

Window:Toggle({ Name = "Anti Ragdoll", Icon = "o", Default = true, Keybind = Enum.KeyCode.R,
    Callback = function(state)
        local char = game.Players.LocalPlayer.Character
        local hum = char and char:FindFirstChildOfClass("Humanoid")
        if hum then
            hum:SetStateEnabled(Enum.HumanoidStateType.Ragdoll, not state)
            hum:SetStateEnabled(Enum.HumanoidStateType.FallingDown, not state)
        end
    end })

Window:Button({ Name = "Unload GUI", Callback = function() Layfield:Destroy() end })

Window:Notify({ Title = "Example Hub", Text = "system online", Icon = "E" })

Make it yours

  • Fork this repo (or copy it) so the modules load from your account, then change the kere0ne/Layfield URL inside src/init.lua and in your loader to your own repo.
  • Rename it: set Name, Subtitle, Icon and Version in main.lua's CONFIG table. That is your hub's branding.
  • Add features: put your logic in the callbacks. Every element call returns an object with Set/Get so your scripts can read and drive the UI.
  • Update safely: because modules load from the repo, editing them on GitHub updates every user on their next execute. Test locally with a copy before pushing big changes.
  • Offline fallback: if you need one file with no network, tell your users to paste src modules in reverse dependency order (theme, util, notify, elements, window, init) or host a bundle yourself.
