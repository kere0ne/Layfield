# CypherUI

A modern, single-file script hub UI framework for Roblox (Luau). Rayfield-style, rebuilt better.

## Features
- Glass-dark window, draggable, minimize/expand (LeftControl default, rebindable)
- Toggle cards: icon, status pill, animated switch, click-to-rebind keybinds
- Buttons, sliders, dropdowns, section labels
- Toast notifications with progress bar
- Mobile friendly (touch drag + tap)
- `CypherUI:Destroy()` unloads everything

## Usage
Paste the whole `CypherUI.lua` into your loader and edit the `EXAMPLE SETUP` section at the bottom to rename the hub and wire your features.
